Sunset Cover Studio turns personal photos and editable titles into an original, multi-panel neon-sunset poster. The static editor runs offline, keeps photos on your device, and exports clean PNG covers for square, portrait, and widescreen posts.

## Run it

```sh
node serve.ts --port 8090
```

Open http://localhost:8090 in a desktop browser. To package the entry:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

## Features

- Four layouts: five-panel Key Art, Duo, Trio, and Solo.
- Import local photos, use bundled samples, assign per panel, and fill all panels at once.
- Drag to pan and tune zoom or Fill/Fit for the selected panel.
- Edit a two-line title and tagline; adjust placement, scale, tracking, outline, glow, and fill.
- Apply four original colour grades with optional sun disc, palms, and film grain.
- Preview and export 1080 × 1080, 1080 × 1350, or 1920 × 1080 PNG covers.
